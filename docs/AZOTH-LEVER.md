# AZOTH 拨杆与按键自定义

1. 退出原来的 G-Helper，运行本分支编译的 `GHelper.exe`。
2. 打开 **外设 → ROG AZOTH**，选择要使用的键盘配置。
3. 在 **拨杆 → 自定义动作** 下分别选择 **上拨、按下、下拨** 的动作，无需奥创。建议上拨选“性能模式升一档”，下拨选“性能模式降一档”；按下可保留默认中键，也可选“性能模式”循环切换。
4. 在左侧 **侧键循环模式** 勾选要保留的模式，点击 **应用**。只想保留音量和性能控制时，勾选“音量”和“自定义”即可。
5. 按拨杆旁的侧键，循环到 **自定义**。每个方向执行各自的动作。

可选择的六种模式为：音量、媒体播放、键盘亮度、OLED 亮度、灯效切换、自定义。至少保留一种。保存时先启用选中项，再关闭其余项，避免出现空循环。关闭“自定义”不会删除三个方向的映射；之后编辑映射也不会改变已经保存的模式选择。

固件不能读回模式的开关状态。首次显示厂商默认的五种模式，并兼容旧版 G-Helper 已启用的自定义模式；请确认勾选内容后点击“应用”。之后显示 G-Helper 按键盘配置保存的记录，有线和无线共用。打开页面或勾选列表不会写入硬件，模式列表需要点击“应用”才保存；可再次应用已有选择，以便在键盘重置或被其他软件更改后恢复。自定义动作仍然单独即时保存：首次尚未应用模式列表时，分配动作会沿用旧版行为启用“自定义”；应用过模式列表后，编辑动作不会改变循环选择。

这份上游代码已有普通按键映射，但没有拨杆配置界面；本分支新增了该入口。旧测试版启用的拨杆开关会被识别为上拨升档、下拨降档；单独修改一个方向不会覆盖另一个方向。下表对应上述推荐映射。

| 当前性能档位 | 上拨 | 下拨 |
| --- | --- | --- |
| 静音 | 平衡 | 静音 |
| 平衡 | 增强 | 静音 |
| 增强 | 增强 | 平衡 |

每次拨动只切换一档，松开不触发。沿用 G-Helper 的 `mode_delay`（默认 1 秒）延迟应用机制；连续拨动时先显示目标档位，停止后应用。原有循环切换动作保留，也继续包含自定义性能档位。新的升降档只在三个基础档位之间移动；从自定义性能档位出发时以其基础档位决定方向，到边界时保留当前自定义档位。

关闭外设设置窗口后仍然有效，G-Helper 必须继续运行。键盘的音量、媒体、亮度等拨杆模式保持原有功能。按下拨杆默认为鼠标中键，可单独修改。

每个方向还可选择普通键、媒体键、鼠标动作或“关闭”。选择列表顶部的默认动作可恢复该方向的滚轮或中键功能。只写入当前选择的方向。键盘固件不支持读回映射，因此页面显示的是 G-Helper 保存的值（未配置时显示默认值），无法识别或备份其他软件配置的动作。

普通按键也能复用这三个性能动作：点击键盘图中的可映射按键，在“按键绑定”列表的 **G-Helper** 分组选择动作。笔记本“额外设置”里已有的可配置快捷键也可选择升档、降档。原来的“性能模式”循环动作保留。

普通键沿用上游的板载组合键宏机制，以 `Ctrl+Shift+Alt+F10/F11/F12` 分别触发循环／升档／降档。这三个组合键需要能被 G-Helper 注册，且 `skip_hotkeys` 未启用；避免将它们分配给其他全局快捷键。拨杆直接读取已验证的厂商事件，不依赖这些组合键。G-Helper 退出后，普通键的宏仍会输出组合键，性能动作不再执行；原生键盘／媒体／鼠标映射仍由键盘执行。

## 适用范围与实机证据

- 针对原版 AZOTH：有线、原装 2.4G 接收器，以及原版 AZOTH 通过 OMNI 接收器连接的路径。
- 在本机原版 AZOTH 的 **2.4G 接收器 `0B05:1A85`** 上验证，键盘固件 `4.00.18`，接收器固件 `3.00.19`。
- 已实测上下拨切换性能、抑制原生滚轮输出及恢复滚轮映射。使用原版 AZOTH 的测试者也已确认包含侧键循环选项和独立拨杆映射的版本可用。
- 有线和 OMNI 路径尚未在本机实测。AZOTH X、Extreme 和蓝牙未开放此设置。

协议依据为 [ASUS Gear Link 的 AZOTH 配置页](https://gearlink.asus.com/view/6787/manifest.json)（1.00.22）及 [OpenAzoth 协议记录](https://github.com/albzO/OpenAzoth/blob/main/docs/PROTOCOL.md)。以下偏移包含 HID report ID：

| 数据 | 含义 |
| --- | --- |
| `03 91 00 00 07` | 当前拨杆模式变为自定义（7） |
| `03 72 01 00 00` | 上拨按下 |
| `03 72 02 00 00` | 按下拨杆 |
| `03 72 04 00 00` | 下拨按下 |
| `03 72 00 00 00` | 松开 |
| `00 71 00 00 00 <mode> <0或1>` | 模式关闭或启用；关闭后侧键跳过该模式 |
| `00 71 01 00 00 07 A4 00 00 00` | 取消自定义上拨的原生输出 |
| `00 71 01 00 00 07 A6 00 00 00` | 取消自定义下拨的原生输出 |

不会安装驱动或修改键盘固件。映射写入后通过 `50 55` 保存到当前键盘配置；三个方向的动作在 G-Helper 中按键盘配置分别存储，有线和无线共用。保存失败时尝试恢复本程序已知的旧映射，不更新本地选择，并显示错误。

## 构建与验证

需要 .NET 10 SDK 和 Windows。`GITHUB_ACTIONS=true` 用于跳过项目原有的构建前退出 G-Helper 动作。

```powershell
dotnet build app/GHelper.sln -c Release -p:GITHUB_ACTIONS=true
dotnet run --project tests/GHelper.Tests -c Release -p:GITHUB_ACTIONS=true
dotnet publish app/GHelper.csproj -c Release -r win-x64 --no-self-contained -p:PublishSingleFile=true -p:GITHUB_ACTIONS=true -o artifacts/azoth-lever-modes
```

测试使用模拟 HID 响应和单独的测试配置，不写真实硬件、不加载用户配置；覆盖三个档位的边界、原有循环行为、自定义性能档位、真实拨杆报文、重复/松开/其他模式过滤、旧开关兼容、三个方向独立保存、按键盘配置隔离、绑定／启用／保存各阶段失败回退、六种模式开关、至少保留一种、保存失败后恢复原循环、关闭自定义后编辑映射不重启该模式、普通键宏与快捷键动作对应，以及中英文资源。

实机验收时，先只保留“音量”和“自定义”，按侧键确认只循环这两项；重新启用其他模式确认恢复；切换键盘配置和重启后检查记录。然后分别从三个性能档位上下拨动，检查提示和主界面；给按下和一个闲置的普通键分配性能动作，检查单次触发；连续拨动确认停在两端；关闭外设窗口后再试；切回音量模式确认只调音量；重新运行 G-Helper 后确认设置保留。
